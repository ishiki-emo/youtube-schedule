プライバシーポリシー

「youtube-schedule」（以下「本ツール」）は、開発者本人が自分の YouTube チャンネル「癒色えも / えもーにんぐ」の動画に公開予約日時を設定するためだけに使う、個人用のローカルスクリプトです。

取得する情報

本ツールは、所有者本人の OAuth 同意に基づき、YouTube Data API v3 を通じて所有者本人のチャンネルの動画情報（動画 ID、タイトル、公開ステータス等）を取得・更新します。他のユーザーの情報を取得することはありません。

情報の利用目的

取得した情報は、非公開動画への公開予約日時の設定という目的にのみ使用します。

情報の管理と第三者提供

すべての処理は所有者本人のコンピュータ上で完結します。取得した情報を外部のサーバーに送信・保存したり、第三者に提供・販売したりすることはありません。OAuth の認証情報（トークン）も所有者本人のコンピュータ内にのみ保存されます。

アクセスの取り消し

所有者は、Google アカウントの「サードパーティ製のアプリとサービス」の設定から、本ツールのアクセス権をいつでも取り消すことができます。

お問い合わせ

本ツールに関するお問い合わせは、YouTube チャンネル「癒色えも / えもーにんぐ」（https://www.youtube.com/@emo-anniv）までお願いします。
